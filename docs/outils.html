Maison Guillard — Les outils du projet

Chaque outil : ce que c'est, à quoi il sert ici, où on le voit dans le code.

Le cœur de l'API

OutilC'est quoiDans le projet
PythonLe langage de programmation du backend.Tout le dossier backend/.
FastAPIFramework web : transforme des fonctions Python en routes d'API (URL + méthode HTTP).app/main.py, app/routers/, les @router.get/post/delete et Depends(...).
UvicornServeur qui fait tourner l'app FastAPI et écoute les requêtes sur un port.uvicorn app.main:app --reload --port 3000
PydanticValidation des données : vérifie la forme du JSON entrant et sortant.app/schemas/. Renvoie 422 automatiquement si les données sont invalides.
python-multipartPermet à FastAPI de lire les formulaires et fichiers envoyés.Upload de photos (UploadFile, File, Form).

La base de données

OutilC'est quoiDans le projet
PostgreSQLLa base de données : stocke admin, catégories, produits, photos.Lancée via Docker.
SQLAlchemyORM : manipule la base avec des classes Python au lieu d'écrire du SQL.app/models/, app/database.py, les db.query(...) dans les services.
AlembicMigrations : crée/modifie les tables en base à partir des models, avec un historique versionné.Dossier alembic/. alembic upgrade head
psycopgLe « pilote » : le câble entre Python/SQLAlchemy et PostgreSQL.Invisible, utilisé par SQLAlchemy (postgresql+psycopg:// dans l'URL).
Docker / docker-composeLance PostgreSQL dans un conteneur, sans l'installer sur Windows.docker-compose.yml. docker compose up -d

Sécurité / authentification

OutilC'est quoiDans le projet
bcryptAlgorithme de hachage de mots de passe, lent exprès pour résister aux attaques par force brute.On stocke password_hash, jamais le mot de passe.
passlibBibliothèque qui simplifie l'usage de bcrypt (hacher / vérifier).CryptContext dans auth_service.py.
JWTJSON Web Token : jeton signé renvoyé au login, prouve qu'on est admin.Header Authorization: Bearer <token>, vérifié par require_admin (401 sinon).
python-joseBibliothèque qui crée et vérifie les JWT.jwt.encode / jwt.decode dans auth_service.py.
python-dotenvCharge les variables du fichier .env (secrets, URL de la base).load_dotenv() dans database.py. .env jamais commité.

Tests

OutilC'est quoiDans le projet
pytestLance les tests : toutes les fonctions test_* dans tests/.python -m pytest -v
unittest.mockIntégré à Python : MagicMock crée une fausse base pour les tests unitaires.tests/unit/
httpx / TestClientSimule un client HTTP qui appelle l'API sans lancer de vrai serveur.tests/integration/

Autour du code

OutilC'est quoiDans le projet
venv (.venv)Environnement virtuel : isole les bibliothèques de ce projet du reste de l'ordinateur.backend/.venv/, installé depuis requirements.txt.
pip / requirements.txtpip installe les bibliothèques ; requirements.txt en liste les versions exactes.pip install -r requirements.txt
Git / GitHubHistorique du code (commits, branches) et sauvegarde en ligne.Branches main, Branche-S5…
Swagger (/docs)Page générée par FastAPI pour voir et tester toutes les routes.http://localhost:3000/docs
React + ViteFrontend (interface du site). Pas encore commencé.frontend/
CloudinaryService d'hébergement d'images. Simulé pour l'instant (fichiers stockés en local).upload_to_cloudinary dans photo_service.py.

Moyen mnémotechnique

Une requête traverse les outils dans cet ordre :
Uvicorn reçoit → FastAPI route → python-jose vérifie le token → Pydantic valide → service → SQLAlchemy → psycopg → PostgreSQL.
Et Alembic a créé les tables avant tout ça.
