Maison Guillard — Les outils du projet

Chaque outil : ce que c'est, à quoi il sert ici, où on le voit dans le code.

Le cœur de l'API

OutilC'est quoiDans le projet
PythonLe langage de programmation du backend.Tout le dossier backend/.
FastAPIFramework web : transforme des fonctions Python en routes d'API (URL + méthode HTTP).app/main.py, app/routers/, les @router.get/post/delete et Depends(...).
UvicornServeur qui fait tourner l'app FastAPI et écoute les requêtes sur un port.uvicorn app.main:app --reload --port 3000
PydanticValidation des données : vérifie la forme du JSON entrant et sortant.app/schemas/. Renvoie 422 automatiquement si les données sont invalides.
email-validatorVérifie qu'une adresse e-mail est bien formée ; utilisé par le type EmailStr de Pydantic.email: EmailStr dans app/schemas/commande.py.
BackgroundTasksFonction de FastAPI : exécute une tâche après avoir répondu au client.Envoi des e-mails de commande dans app/routers/commandes.py : le client n'attend pas l'envoi.
python-multipartPermet à FastAPI de lire les formulaires et fichiers envoyés.Upload de photos (UploadFile, File, Form).

La base de données

OutilC'est quoiDans le projet
PostgreSQLLa base de données : stocke admin, catégories, produits, photos, commandes et réglages.Lancée via Docker.
SQLAlchemyORM : manipule la base avec des classes Python au lieu d'écrire du SQL.app/models/, app/database.py, les db.query(...) dans les services.
AlembicMigrations : crée/modifie les tables en base à partir des models, avec un historique versionné.Dossier alembic/. alembic upgrade head
psycopgLe « pilote » : le câble entre Python/SQLAlchemy et PostgreSQL.Invisible, utilisé par SQLAlchemy (postgresql+psycopg:// dans l'URL).
Docker / docker-composeLance PostgreSQL dans un conteneur, sans l'installer sur Windows.docker-compose.yml. docker compose up -d

Sécurité / authentification

OutilC'est quoiDans le projet
bcryptAlgorithme de hachage de mots de passe, lent exprès pour résister aux attaques par force brute.On stocke password_hash, jamais le mot de passe.
passlibBibliothèque qui simplifie l'usage de bcrypt (hacher / vérifier).CryptContext dans auth_service.py.
JWTJSON Web Token : jeton signé renvoyé au login, prouve qu'on est admin.Header Authorization: Bearer <token>, vérifié par require_admin (401 sinon).
python-joseBibliothèque qui crée et vérifie les JWT.jwt.encode / jwt.decode dans auth_service.py.
python-dotenvCharge les variables du fichier .env (secrets, URL de la base).load_dotenv() dans database.py. .env jamais commité.

Tests

Autour du code

OutilC'est quoiDans le projet
venv (.venv)Environnement virtuel : isole les bibliothèques de ce projet du reste de l'ordinateur.backend/.venv/, installé depuis requirements.txt.
pip / requirements.txtpip installe les bibliothèques ; requirements.txt en liste les versions exactes.pip install -r requirements.txt
Git / GitHubHistorique du code (commits, branches) et sauvegarde en ligne.Branches main, Branche-S5, Branche-S6…
Swagger (/docs)Page générée par FastAPI pour voir et tester toutes les routes.http://localhost:3000/docs
smtplib / SMTP Gmailsmtplib est le client e-mail intégré à Python ; SMTP est le protocole d'envoi d'e-mails. En développement, on passe par le serveur SMTP de Gmail avec un mot de passe d'application.app/services/email_service.py, variables SMTP_* et EMAIL_* du .env. Mot de passe jamais commité.
CloudinaryService d'hébergement d'images. Simulé pour l'instant (fichiers stockés en local).upload_to_cloudinary et public_url dans photo_service.py.

Le frontend (interface du site)

OutilC'est quoiDans le projet
Node.js / npmNode exécute du JavaScript hors du navigateur ; npm installe les bibliothèques JavaScript.frontend/package.json (liste des dépendances), npm install.
ReactBibliothèque pour construire l'interface en composants (des fonctions qui renvoient du JSX, un HTML dans le JavaScript).frontend/src/components/, frontend/src/pages/.
ViteOutil de développement : serveur avec rechargement instantané, et « build » qui prépare les fichiers optimisés pour la mise en ligne.npm run dev (port 5173), npm run build, vite.config.js.
Proxy ViteRedirige les appels /api du navigateur vers FastAPI : le site et l'API semblent venir de la même adresse, donc pas besoin de configurer CORS.server.proxy dans vite.config.js.
React RouterAssocie chaque URL à une page, sans recharger le site.src/main.jsx : /, /boutique, /produits/:id, /qui-sommes-nous, /contact, /panier, /commande.
fetchFonction du navigateur qui appelle l'API et récupère le JSON.src/api/client.js (apiGet, apiPost), utilisé via le hook useApi et pour envoyer une commande.
oxlintAnalyse le code JavaScript pour repérer les erreurs et les mauvaises pratiques.npm run lint, .oxlintrc.json.
node:testLanceur de tests intégré à Node : aucune bibliothèque à installer.npm test → src/utils/*.test.js (produit, panier, navigation).
Context ReactPartage une donnée entre tous les composants sans la passer de parent en enfant.Le panier : src/context/PanierContext.jsx, lu avec usePanier().
localStoragePetit stockage du navigateur, propre à chaque visiteur, qui survit au rechargement de la page.Le contenu du panier (clé maison-guillard-panier).
Animations CSStransition anime un changement de style ; @keyframes décrit une animation étape par étape.Fondu des photos (.galerie__grande), glissement entre les pages (TransitionPages.jsx). Coupées si le visiteur a demandé de réduire les animations.
CSS (variables)Mise en forme du site ; les couleurs et polices sont définies une fois dans des variables réutilisées partout.src/index.css (--couleur-fond, --couleur-accent…).
Google Fonts (Jost)Police du site, chargée depuis Google Fonts.<link> dans frontend/index.html.
SVGFormat d'image vectoriel (des tracés, pas des pixels) : net à toutes les tailles.Logo dans src/components/Logo.jsx, public/favicon.svg.
WebPFormat d'image compressé, plus léger que JPEG à qualité égale.src/assets/vitrine/, backend/seed_photos/.

Moyen mnémotechnique

Une requête traverse les outils dans cet ordre :
Navigateur → React appelle fetch → proxy Vite → Uvicorn reçoit → FastAPI route → python-jose vérifie le token (routes admin) → Pydantic valide → service → SQLAlchemy → psycopg → PostgreSQL.
Et Alembic a créé les tables avant tout ça.
