# S6 bis — Vitrine (accueil, qui sommes-nous, contact, DA) Implementation Plan

**Goal:** Turn the public catalogue into a "vitrine + e-shop": new home page, "Qui sommes-nous" and
"Contact" pages, shop moved to `/boutique`, new art direction (Jost, sand palette, SVG logo).

**Architecture:** Frontend only. `Layout` renders `Header` + full-width `<main>` + `Footer`; each
page constrains its own width with `.contenu` so the home hero can be full-bleed. The logo is an
inline SVG component coloured with `currentColor`. One new pure helper (`piecesChoisies`) picks
the home page's featured produits and is unit-tested with `node --test`.

**Tech Stack:** React 19, react-router-dom 7, Vite 8, oxlint, `node:test`, Google Fonts (Jost).

**Spec:** `docs/specs/2026-10-10-s6-vitrine-design.md`

**Who types what:** everything here is frontend — written for Remy, explained afterwards.

## Global Constraints

- Branch `Branche-S6`; Conventional Commits; no trailers; no tool names in tracked files.
- No backend change; backend suite must stay green (64 tests).
- One font: Jost 300/400/500 from Google Fonts. No serif.
- Palette tokens exactly: fond `#faf8f4`, surface `#ffffff`, texte `#1f1d1a`, texte-doux
  `#7a736b`, accent `#b8a58c`, filet `#e8e2d8`, erreur `#a33`.
- Ambience images are decorative: empty `alt=""` unless the image carries information.
- Every pre-existing behaviour of the catalogue and fiche (filters in URL, 404s, error + retry,
  disabled cart/devis buttons) is preserved; only paths and styling change.

  assert.deepEqual(piecesChoisies([{ id: 1, disponibilite: 'disponible', photos: [] }], 3), [])

Run `npm test` → FAIL (`piecesChoisies` is not exported).

- [ ] **Step 2: Implement** — append to `produit.js`:

```js
const RANG_DISPONIBILITE = { disponible: 0, sur_commande: 1, rupture: 2 }

// Home page selection: only produits that have a photo, purchasable ones first.
// Array.prototype.sort is stable, so the API order is kept among equals.
export function piecesChoisies(produits, n) {
  return produits
    .filter((p) => p.photos?.length > 0)
    .sort((a, b) => (RANG_DISPONIBILITE[a.disponibilite] ?? 3) - (RANG_DISPONIBILITE[b.disponibilite] ?? 3))
    .slice(0, n)
}
```

Run `npm test` → 9 PASS.
