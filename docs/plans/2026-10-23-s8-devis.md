# S8 — Demande de devis (version de base) Implementation Plan

**Goal:** A visitor sends a quote request from the Contact page (optionally about a product); it
is stored as `nouveau` and, if the admin email setting is on, the artisan and the client get an
email.

**Architecture:** One new table `devis` and one public route `POST /api/devis`, following the
exact pattern of S7 orders (schema → service → router, emails in a background task). Frontend: a
`FormulaireDevis` component on the Contact page, reached from the product page through
`/contact?produit=<id>`.

**Tech Stack:** FastAPI, SQLAlchemy, Alembic, Pydantic, pytest; React, react-router-dom, `node:test`.

**Spec:** `docs/specs/2026-10-23-s8-devis-design.md`

**Who types what:** Remy types the backend app code; test files and the frontend are written for
him and explained.

## Global Constraints

- Branch `Branche-S8` (from `Branche-S7`, which holds the spec). Conventional Commits, no trailers.
- Migrations applied to both databases (`maison_guillard` and `maison_guillard_test`).
- Any disponibilité is accepted for `produit_id`; unknown product → 422.
- `devis.produit_id` uses `ondelete="SET NULL"`.
- Emails reuse `parametre.email_commande_actif`; an SMTP failure never fails the request.

## Review Focus

- A product referenced by a quote is deleted → the quote stays, `produit_id` becomes `NULL` (Task 3).
- `/contact?produit=abc` or an id that does not exist → the form still works, without « À propos de »,
  and sends no `produit_id` (Task 4).
- Description of spaces only → 422 (Task 2).
- Email setting on, SMTP down → still 201 (Task 3).
- Double click on « Envoyer » → one request only (button disabled while sending, Task 4).

```python
from sqlalchemy import Column, DateTime, Enum as SqlEnum, ForeignKey, Integer, String
from sqlalchemy.orm import relationship
from sqlalchemy.sql import func

from app.database import Base


class StatutDevis(str, enum.Enum):
    nouveau = "nouveau"
    en_discussion = "en_discussion"
    accepte = "accepte"
    refuse = "refuse"


class Devis(Base):
    __tablename__ = "devis"

    id = Column(Integer, primary_key=True, index=True)
    nom_client = Column(String, nullable=False)
    email = Column(String, nullable=False)
    telephone = Column(String, nullable=True)
    # SET NULL: deleting the produit keeps the quote, only the link is lost.
    produit_id = Column(Integer, ForeignKey("produit.id", ondelete="SET NULL"), nullable=True)
    description_projet = Column(String, nullable=False)
    statut = Column(
        SqlEnum(StatutDevis, name="statut_devis_enum"),
        nullable=False,
        default=StatutDevis.nouveau,
    )
    created_at = Column(DateTime(timezone=True), server_default=func.now())
    produit = relationship("Produit", lazy="selectin")
```

```python
from sqlalchemy.orm import Session

from app.models.devis import Devis
from app.models.produit import Produit
from app.services.commande_service import ProduitIntrouvableError


def create(db: Session, data: dict) -> Devis:
    # Any disponibilité is fine for a quote: only an unknown produit is refused.
    produit_id = data.get("produit_id")
    if produit_id is not None:
        if db.query(Produit).filter(Produit.id == produit_id).first() is None:
            raise ProduitIntrouvableError(produit_id)

    devis = Devis(**data)
    db.add(devis)
    db.commit()
    db.refresh(devis)
    return devis
```

- [ ] **Step 3: `backend/app/routers/devis.py`**

```python
from fastapi import APIRouter, BackgroundTasks, Depends, HTTPException
from sqlalchemy.orm import Session

from app.database import get_db
from app.schemas.devis import DevisIn, DevisOut
from app.services import commande_service, devis_service, email_service, parametre_service

router = APIRouter(prefix="/api/devis", tags=["Devis"])


@router.post(
    "",
    response_model=DevisOut,
    status_code=201,
    summary="Envoyer une demande de devis",
    responses={422: {"description": "Données invalides ou produit introuvable"}},
)
def create_devis(
    payload: DevisIn,
    background_tasks: BackgroundTasks,
    db: Session = Depends(get_db),
):
    try:
        devis = devis_service.create(db, payload.model_dump())
    except commande_service.ProduitIntrouvableError as erreur:
        raise HTTPException(status_code=422, detail=f"Produit n°{erreur.produit_id} introuvable")

    if parametre_service.get(db).email_commande_actif:
        try:
            messages = email_service.messages_nouveau_devis(devis)
        except KeyError:
            messages = []
        if messages:
            background_tasks.add_task(email_service.envoyer, messages)
    return devis
```
